## Guidelines

- **Use demo data only.** Register a throwaway account and audit a well-known public
  protocol. Never publish a real user's report, email address, or audit history.
- **Check the frame before saving.** Crop out browser autofill dropdowns, notification
  toasts, password managers, and any devtools panel showing an `Authorization` header,
  bearer token, or API key.
- **Capture at 1280×800 or wider**, then downscale. PNG for UI, PNG or JPG for the PDF page.
- **Keep each file under ~500 KB** so the repository stays light to clone.
- **Consider light and dark mode consistency** — pick one and use it across all six.
